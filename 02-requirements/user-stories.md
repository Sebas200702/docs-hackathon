# User Stories

Personas en `01-product/personas.md`. Cada historia enlaza requisitos.

## Onboarding

**US-001** Como Valentina, quiero registrar mis ingresos y gastos fijos para saber cuánto tengo realmente. → FR-010 … FR-014

**US-002** Como estudiante, quiero introducir pocos datos para obtener valor en menos de dos minutos. → FR-010 … FR-015

## Presupuesto

**US-010** Como usuaria, quiero ver qué está comprometido, qué puedo gastar y qué puedo ahorrar. → FR-020, FR-021

**US-011** Como usuaria, quiero entender por qué se propone esa distribución, con mis números. → FR-022

## Recomendaciones

**US-020** Como Valentina, quiero una sola recomendación clara que no me deje sin pasaje. → FR-030, FR-031, FR-033

**US-021** Como usuaria, quiero aceptar, cambiar el monto o rechazar una recomendación. → FR-032

**US-022** Como Valentina, quiero preguntar si me alcanza para una compra y recibir una respuesta honesta. → FR-034

## Metas

**US-030** Como Andrés, quiero una meta para mi curso de certificación que me diga cuánto aportar al mes. → FR-040, FR-043

**US-031** Como usuaria, quiero ver cuánto he avanzado. → FR-041

## Movimiento

**US-040** Como usuaria, quiero aprobar la separación hacia mi meta para no hacerlo a mano. → FR-050, FR-052

**US-041** Como usuaria, quiero ver monto, origen y destino antes de aprobar. → FR-051

**US-042** Como usuaria, quiero que un doble toque no separe el dinero dos veces. → FR-054

## Gamificación

**US-050** Como Andrés, quiero que un mes sin capacidad no me castigue. → FR-062

**US-051** Como usuaria, quiero retos ligados a hábitos útiles. → FR-061

## Grupo

**US-060** Como Mariana, quiero definir cuánto le corresponde a cada uno del stand al final. → FR-080, FR-081

**US-061** Como Luis, quiero que mi aporte del mes se adapte a mi capacidad sin cambiar mi responsabilidad final. → FR-082

## Ciudad

**US-070** Como analista de la Alcaldía/universidad/SENA, quiero ver en qué momento del mes los jóvenes se quedan sin margen, sin ver datos personales. → FR-090

**US-071** Como usuaria, quiero decidir si mis datos cuentan para esos insights y poder retirarme. → FR-091
