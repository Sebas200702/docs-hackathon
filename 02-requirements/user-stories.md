# User Stories

## Onboarding

**US-001** Como estudiante, quiero registrar mis ingresos y obligaciones para conocer mi situación financiera.

**US-002** Como estudiante, quiero introducir pocos datos para obtener valor rápidamente.

## Presupuesto

**US-010** Como usuario, quiero recibir una distribución presupuestaria para saber cómo organizar mi dinero.

**US-011** Como usuario, quiero entender por qué se propone una distribución.

## Recomendaciones

**US-020** Como usuario, quiero recibir recomendaciones adaptadas a mi situación.

**US-021** Como usuario, quiero aceptar, modificar o rechazar una recomendación.

## Metas

**US-030** Como usuario, quiero crear una meta para darle propósito a mi ahorro.

**US-031** Como usuario, quiero ver cuánto he avanzado.

## Open Payments

**US-040** Como usuario, quiero aprobar una distribución para evitar realizar manualmente el movimiento.

**US-041** Como usuario, quiero conocer qué cantidad y destino serán utilizados antes de aprobar.

## Gamificación

**US-050** Como usuario, quiero ver mi progreso para mantener continuidad.

**US-051** Como usuario, quiero completar retos relacionados con mis hábitos financieros.

## Grupo

**US-060** Como miembro de una meta grupal, quiero tener una responsabilidad final definida.

**US-061** Como miembro, quiero que mi aporte periódico se adapte a mi capacidad sin cambiar mi responsabilidad final.
