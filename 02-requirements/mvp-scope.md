# Alcance MVP

## P0 — Imprescindible

1. Login.
2. Onboarding.
3. Estado financiero.
4. Presupuesto automático.
5. Recomendaciones.
6. Meta financiera.
7. Confirmación de acción.
8. Open Payments/simulación.
9. Registro/auditoría.

## P1 — Importante

1. Revisión semanal.
2. Gamificación.
3. Retos.
4. Meta grupal.
5. Simulador de decisiones.

## P2 — Posterior

1. Clasificación avanzada.
2. Personalización avanzada.
3. Integraciones bancarias.
4. Automatizaciones avanzadas.
5. Perfil financiero.

## Regla de alcance

No se incorpora una funcionalidad nueva al MVP si no mejora directamente el loop:

Entender → decidir → aprobar → actuar → progresar.
