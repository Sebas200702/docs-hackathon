# Requisitos Funcionales

## Autenticación

- FR-001: El sistema debe permitir registro/login.
- FR-002: El sistema debe mantener una sesión autenticada.
- FR-003: El sistema debe asociar información financiera al usuario autenticado.

## Onboarding

- FR-010: Capturar ingresos.
- FR-011: Capturar gastos fijos.
- FR-012: Capturar saldo disponible.
- FR-013: Capturar obligaciones pendientes.
- FR-014: Capturar saldo mínimo protegido.
- FR-015: Permitir crear una primera meta.

## Presupuesto

- FR-020: Calcular margen.
- FR-021: Generar distribución presupuestaria.
- FR-022: Mostrar explicación de la distribución.
- FR-023: Permitir ajustes del usuario.

## Recomendaciones

- FR-030: Generar recomendaciones contextualizadas.
- FR-031: Mostrar razón de la recomendación.
- FR-032: Permitir aceptar, modificar o rechazar.
- FR-033: Aplicar reglas de seguridad antes de ofrecer una acción.

## Metas

- FR-040: Crear meta.
- FR-041: Mostrar progreso.
- FR-042: Registrar aportes.
- FR-043: Calcular cantidad restante.

## Open Payments

- FR-050: Preparar una distribución aprobada.
- FR-051: Requerir confirmación antes del movimiento.
- FR-052: Ejecutar/simular el movimiento.
- FR-053: Registrar resultado.
- FR-054: Evitar duplicados mediante idempotencia.

## Gamificación

- FR-060: Registrar progreso.
- FR-061: Gestionar retos.
- FR-062: Gestionar rachas.
- FR-063: Gestionar niveles/badges.

## Revisión

- FR-070: Generar revisión semanal.
- FR-071: Mostrar una acción prioritaria.
