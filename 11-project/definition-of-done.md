# Definition of Done

Una funcionalidad está terminada cuando:

- Existe user story.
- Existe requisito.
- Las reglas están definidas.
- Input/output está validado.
- Existen estados loading/error.
- Existen tests relevantes.
- Existe auditoría cuando corresponde.
- Hay seed/demo data.
- Otro miembro del equipo puede recorrerla.
- No rompe el happy path.
- La funcionalidad cumple sus criterios de aceptación.
