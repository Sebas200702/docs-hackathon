# Definition of Done

Una funcionalidad está terminada cuando:

- Existe user story y requisito (FR) enlazados.
- Las reglas (BR) están definidas.
- Input/output validado con Zod.
- Existen estados loading/error/vacío.
- Existen tests relevantes (FS/AI/PY) en verde.
- Existe auditoría cuando hay decisión o movimiento.
- Hay seed/demo data.
- Otro miembro del equipo puede recorrerla en un celular.
- No rompe el happy path del guion de demo.
- Cumple sus criterios de aceptación (AC).
- Si algo es simulado, la UI lo indica.
