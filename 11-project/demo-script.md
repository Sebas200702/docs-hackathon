# Demo Script

## 0:00 — Problema

Gestionar dinero no debería sentirse como otra tarea administrativa.

## 0:20 — Usuario

Presentar estudiante con ingresos limitados.

## 0:40 — Onboarding

Introducir pocos datos.

## 1:00 — Presupuesto

Mostrar distribución automática.

## 1:20 — Recomendación

Mostrar acción contextual.

## 1:40 — Open Payments

Usuario revisa y aprueba distribución.

## 2:00 — Resultado

Mostrar movimiento y actualización de meta.

## 2:20 — Gamificación

Mostrar progreso/racha/reto.

## 2:40 — Diferenciador

Explicar que el sistema no solo recomienda: puede materializar una acción financiera mediante Open Payments bajo aprobación.

## 3:00 — Cierre

> El objetivo no es hacer que el usuario gestione mejor una app financiera. Es hacer que tenga que gestionar menos su dinero para tomar mejores decisiones.
