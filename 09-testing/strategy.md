# Estrategia de Testing

## Unit

- Cálculos financieros.
- Reglas.
- Policy Engine.
- Adaptadores.

## Integration

- API + DB.
- Decision Provider + fallback.
- Payment flow.

## Failure

- IA timeout.
- IA 429.
- Respuesta inválida.
- DB unavailable.
- Open Payments unavailable.
- Doble click.
- Porcentajes inválidos.
- Capacidad segura cero.

## Manual
