# UX — Metas

## Plantillas de meta de oportunidad (FR-015)

| Categoría | Ejemplo | Por qué está |
|---|---|---|
| `herramienta_estudio` | Portátil, tablet de diseño, kit de herramientas | Estudio y empleabilidad |
| `curso_certificacion` | Certificación técnica, curso de inglés | Empleabilidad |
| `emprendimiento` | Insumos, stand de feria | Emprendimiento |
| `emergencia` | Colchón para imprevistos | Inclusión y estabilidad |
| `otro` | Libre | — |

## Crear

Plantilla → Nombre → Monto objetivo → Fecha → Crear. Se muestra de inmediato el aporte mensual necesario (FR-043): "Para llegar en septiembre necesitas $150.000 al mes".

## Mostrar

- Progreso (%) y barra.
- Aportado / restante.
- Fecha y aporte mensual necesario.
- Próxima acción recomendada.

## Aporte

El sistema recomienda un monto según capacidad segura. El usuario puede cambiarlo o rechazarlo y siempre confirma el movimiento (`open-payments-experience.md`).
