# User Flows

## Flujo principal

Login → Onboarding → Estado financiero → Presupuesto → Meta → Recomendación → Confirmación → Open Payments → Resultado → Progreso → Siguiente acción.

## Ingreso extraordinario

Ingreso → Detección → Distribución sugerida → Explicación → Confirmación → Open Payments → Actualización.

## Revisión semanal

Semana → Resumen → Desviación/oportunidad → Acción recomendada → Usuario decide → Resultado.

## Compra

Compra → Comprobación de capacidad → Resultado: recomendable / no recomendable → Explicación.

## Meta grupal

Crear meta → Definir miembros → Definir porcentajes → Validar 100% → Activar → Calcular capacidad → Recomendar aporte → Confirmar → Registrar.
