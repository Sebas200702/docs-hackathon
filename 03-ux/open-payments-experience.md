# UX — Open Payments

## Principio

El usuario siempre entiende qué movimiento está aprobando.

## Flujo

Recomendación → Detalle → Cantidad → Destino → Explicación → Aprobar/Rechazar → Open Payments → Resultado.

## Estados

- Pendiente de aprobación.
- Procesando.
- Completado.
- Rechazado.
- Error.
- Reintentable.

## Mensaje UX

La automatización debe sentirse como una ayuda, no como pérdida de control.
