# UX — Onboarding

## Objetivo

Obtener el mínimo contexto necesario para producir el primer valor rápidamente.

## Datos

- Ingreso.
- Gastos fijos.
- Saldo disponible.
- Obligaciones pendientes.
- Saldo protegido.
- Meta opcional.

## Resultado

El usuario termina viendo una lectura sencilla:

- margen;
- dinero comprometido;
- dinero disponible;
- primera recomendación;
- meta.

## Principios

- Pocos pasos.
- Lenguaje cotidiano.
- Evitar formularios financieros extensos.
- Mostrar progreso del onboarding.
