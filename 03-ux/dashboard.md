# UX — Dashboard

## Objetivo

Responder rápidamente:

1. ¿Cómo estoy?
2. ¿Qué puedo hacer?
3. ¿Qué estoy intentando conseguir?

## Bloques

- Estado financiero.
- Dinero disponible.
- Obligaciones.
- Meta principal.
- Recomendación prioritaria.
- Progreso.
- Reto actual.

## Regla

El dashboard no debe convertirse en una colección de gráficos. Cada bloque debe ayudar a comprender o actuar.
