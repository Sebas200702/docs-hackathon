# Open Payments — Overview

## Propósito

Open Payments permite llevar la autonomía del producto desde una recomendación hasta una acción financiera autorizada.

## Supuesto MVP

Para la hackathon se asume que las cuentas utilizadas son wallets compatibles con Open Payments y que el entorno disponible es demo/sandbox.

## Casos

- Aportes a metas.
- Separación de dinero.
- Microahorro.
- Pagos recurrentes futuros.
- Verificación de ownership cuando corresponda.

## Principio

No se integra Open Payments solo para demostrar una API. Debe producir una acción financiera relevante dentro del flujo del producto.
