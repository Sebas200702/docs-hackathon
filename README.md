# docs-hackathon

## Copiloto de Salud Financiera — Documentación

Sistema de presupuesto autónomo orientado a estudiantes universitarios con ingresos limitados. El producto combina presupuesto, recomendaciones, progreso, gamificación y automatización financiera mediante Open Payments.

## Fuente documental

Esta documentación consolida el PRD y el Plan Técnico del proyecto. Cuando existe una decisión específica del equipo, prevalece la decisión más reciente acordada por el equipo.

## Mapa

- `01-product/` — visión, usuario y producto.
- `02-requirements/` — requisitos y alcance.
- `03-ux/` — experiencia y flujos.
- `04-domain/` — dominio y reglas financieras.
- `05-open-payments/` — aplicación de Open Payments.
- `06-ai/` — IA, decisiones y protección.
- `07-architecture/` — arquitectura del sistema.
- `08-technical/` — API, datos, contratos y seguridad.
- `09-testing/` — estrategia y casos críticos.
- `10-operations/` — desarrollo, despliegue y contingencia.
- `11-project/` — roadmap, backlog y demo.
- `12-decisions/` — decisiones arquitectónicas.

## Principio rector

> El sistema propone; las reglas protegen; el usuario confirma; Open Payments ejecuta; el sistema registra.

## Trazabilidad

Problema → Objetivo → Feature → Requisito → Regla → Dominio → API → Implementación → Test.
